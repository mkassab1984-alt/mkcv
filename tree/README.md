# Mamdouh Kassab Ismail — Interactive Palestinian Olive Tree CV Website

موقع السيرة الذاتية التفاعلي لـ **ممدوح كساب إسماعيل** (*كاتب محتوى أول ثنائي اللغة · استشاري تسويق ومدير إبداعي — جدة، المملكة العربية السعودية*)، تتوسطه **شجرة زيتون فلسطينية معمّرة** مرسومة بطباعة حجرية دافئة غير لامعة (`#C4C8D2` / `#C6CAD2` / `#DCE0E8`) فوق سماء ليلية بلون كحلي عميق (`#001f3f`) مع مقطع أرضي سفلي (`#00152b`) يكشف جذور شجرة الزيتون المتفرعة وصخور الأنهار الجوفية المشققة ومسارات النقاط الفضية، ومحرك الكاميرا المصممة والآلة الكاتبة الحرفية ثنائية اللغة (`IBM Plex Sans` و `IBM Plex Sans Arabic`).

## أبرز الخصائص البصرية والتفاعلية

1. **لوحة الألوان والطباعة الحجرية (`#C6CAD2` + `#ink-roughen`)**:
   - سماء كحلية عميقة (`#001f3f`) ومقطع تربة سفلي (`#00152b`) مع طبقة تحبيب طباعي شاملة في أعلى المشهد (`#film-grain` بـ `z-index: 9999` وشفافية `0.075`).
   - نصوص اللوحة ترسم بالكامل بتأطير داكن وظل ساقط (`strokeText` + `fillText`) بلون طبشوري مطفأ (`#C6CAD2`، وتمرير نشط `#DCE0E8`، وبيانات فرعية `#9AA2B2`) مع الحفاظ الكامل على اتصال الحروف العربية في `IBM Plex Sans Arabic`.
2. **نمو الشجرة النقطي الترتيبي والكتابة الحرفية المتقطعة**:
   - نمو عضوي للشجرة بنسبة `1:1` دون أي تمدد مطاطي عبر خريطة عتبات نمو نقطية (`growAt`) تبدأ من الجذع نحو الأغصان ثم عناقيد الأوراق البيضاوية مع تقريب هادئ للكاميرا (`1.05 -> 1.0`).
   - كتابة حرفية متقطعة حادة مع وقفة دقيقة عند علامات الترقيم ومسح عكسي نظيف عند طيّ الفروع.
3. **شريط التحكم السفلي والمقطع الأرضي**:
   - **زر الرجوع النباتي السفلي الأيسر (`68×38`)**: كبسولة مطبوعة (`#C2C5CC` مع تحبيب نقطي عالي الدقة وفلتر `#ink-roughen`) تضم غصن زيتون منحنياً بورقة نابطة وبرعم دائري.
   - **مشغل الموسيقى القابل للتوسيع في الزاوية السفلى اليمنى**: كبسولة (`▶/⏸`، `artist · title...`، سهم القائمة `▴`، فتح المقطوعة في يوتيوب `↗`، المقطوعة التالية `⏭`) مع فراشة فضية مرفرفة وأعشاب أفق بارزة وعبارة همس قابلة للنقر لبدء التشغيل أو إيقافه مباشرة عبر `5` مقطوعات مرتبة في `music/playlist.js`.

## هيكل الملفات

- `index.html` — الصفحة الرئيسية المرتبطة بملفات مجلد `tree/` و `music/`.
- `standalone.html` — نسخة مكتفية ذاتياً في ملف واحد تضم التنسيقات والأيقونة والبيانات والمحرك بالكامل.
- `music/playlist.js` — قائمة الـ `5` مقطوعات الموسيقية المرتبة مع المعرّفات الاحتياطية التلقائية.
- `tree/src/data.js` — بيانات السيرة الذاتية الرسمية باللغتين الإنجليزية والعربية (`نبذة عني` والصورة الشخصية ثنائية الحالة).
- `tree/src/main.js` — محرك رسم شجرة الزيتون والنمو النقطي والكاميرا والكتابة الحرفية ومشغل الصوت.
- `tree/css/style.css` — تنسيقات الصفحة وكبسولات التحكم ومشغل الموسيقى.
- `tree/icon/favicon.svg` — أيقونة شجرة الزيتون على خلفية `#001f3f`.
